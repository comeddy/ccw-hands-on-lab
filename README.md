# English

## Overview

This repository hosts the rendered HTML hands-on lab guides for the Claude Code Deep Dive Workshop: six chapter labs (Ch1-Ch6), four capstone labs (main, B, C, D), and three reference pages, entered through the `index.html` portal.

- **Live site**: [comeddy.github.io/ccw-hands-on-lab](https://comeddy.github.io/ccw-hands-on-lab/)
- **Source repository**: [comeddy/claude-code-workshop](https://github.com/comeddy/claude-code-workshop) — the lab HTML files are authored under `ccw-hands-on-lab/` there and mirrored here for deployment.
